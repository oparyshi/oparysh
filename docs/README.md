# Документация oparysh

Первичный источник по всем форматам — [`DOCS.md`](../DOCS.md) в корне репозитория.
Папка `docs/` содержит практические руководства по темам.

| Файл | Содержание |
|---|---|
| [repositories.md](repositories.md) | Репозитории: структура, `index.toml`, создание и публикация своего репо, подключение и синхронизация |

Сюда будут добавляться другие руководства:

- `recipes.md` — подробный разбор формата рецепта и сборочных систем (DOCS.md §5);
- `configuration.md` — тюнинг `oparysh.conf` (DOCS.md §6);
- `integrity.md` — SHA-256 и подписи (DOCS.md §9).

Краткая справка по любым командам также доступна через `oparysh <command> --help`.
